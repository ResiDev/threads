==== note 9, card
•  comment   light now builds the tree on every cursor move and scroll

Before, paint recoloured rows built once per draw. Now each light runs M.tree once or twice, and
count for every directory, which walks its subtree again, so a deep tree is counted more than
once; and a scroll that moves the cursor runs light twice (#step:8). Measured from nvim -l: 1.5
ms a fit for 500 files in 70 directories, one lit in the middle, height 40. Reviews have tens of
files, so this is fine; worth knowing if light ever feels slow on a large diff.
