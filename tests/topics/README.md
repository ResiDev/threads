# Topics agents wrote

Test data for `draw/` and the screen tests: topics in the format of
`design/format.ts`, written by agents following
`skills/threads/SKILL.md` and nothing else, about changes in
this repository. Each says in its `diff` the commits it is about; check
out the repository at its `head`, put the topic in `.threads/`, and
every chunk in it is found. `make try` does that for all of them.
